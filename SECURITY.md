# Security Policy

SentinelAgent Guard is a security tool, so we take vulnerabilities in it seriously.

## Reporting a vulnerability

**Do not open a public issue for security reports.** Email **security@sentinelreign.com**
with details and, ideally, a minimal reproduction. We aim to acknowledge within
72 hours and to coordinate a fix and disclosure timeline with you.

Please do not run tests against systems you do not own or have permission to test.

## Scope

The detection engine, SDK, and CLI in this repository. The hosted SaaS
(guard.sentinelreign.com) has its own reporting channel at the same address.
